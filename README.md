# CodeBox Frontend — Online Coding Platform

## 🚀 Live Demo
https://codebox-frontend.vercel.app

## 🛠️ Tech Stack
- Next.js + TypeScript
- Tailwind CSS
- Redux Toolkit
- JWT Authentication
- Axios

## ✨ Features
- User authentication
- Online code editor
- Real-time collaboration

## 🎭 Demo Access

Click **"Try Demo Account"** on the login page for instant access — no signup or OTP needed:
```
Email: demo@codebox.com
Password: Demo@1234
```
(Note: data periodically resets — real signup is also available.)

## ⚙️ Setup Locally
- Clone the repo
- Run `npm install`
- Create `.env.local` file
- Run `npm run dev`
